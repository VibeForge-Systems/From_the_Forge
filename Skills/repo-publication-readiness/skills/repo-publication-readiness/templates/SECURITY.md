# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. That opens a private advisory visible only to the
maintainers and you.

If you cannot use GitHub, email `SECURITY-CONTACT@example.org` <!-- replace before publishing -->.

Include what you found, how to reproduce it, the affected version or commit,
and what an attacker could do with it.

- An assessment and, where it is a real issue, a fix or mitigation plan.
